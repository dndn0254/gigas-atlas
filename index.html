The resource

Eight studies, one genome, one naming scheme

Eight oyster single-cell studies were published by different labs, with different protocols, on a superseded genome, so their cell types could not be compared. We reprocessed all public raw reads with one pipeline. Tissue, lab and protocol are fully confounded, so we keep six atlases and link them by comparing cell-type names instead of merging cells.

Raw reads

27 runs, 9 BioProjects, 20 libraries (14 whole cell, 6 nuclei) from 4 countries.

One genome

All reads mapped to xbMagGiga1.1 with the RefSeq annotation RS_2024_06.

Six atlases

Shared QC, then Seurat 5 (R): LogNormalize, vst genes, PCA, SNN graph, Louvain clusters, RPCA within tissue. Names graded by evidence: authors' label, marker support, confidence.

Linked by name

Cell types compared across datasets with the MetaNeighbor R package (AUROC), kept only if reciprocal top hits and stable in 6 of 9 re-runs.

Reproduced99.9%

of the achievable agreement with the authors' gastrula labels; 98.9% for the trochophore larva.

Hemocytes in every tissue7

blood hemocyte types reappear in gonad, ganglia and mantle, including ganglion cells first described as phagocytic glia (AUROC 0.999).

R (Seurat) and Python

gigasatlas

Names the cells of new oyster single-cell data with these references, directly on a Seurat object in R or on AnnData in Python (same models, same answers), scores clusters and gene lists, and converts old gene IDs. Accuracy on cells from held-out libraries, studies or labs: 73 to 92%.

Bundled models
development73 types, embryo and larva
hemocyte15 types, blood
gonad28 types, nuclei
ganglia49 types, nuclei
mantle21 types
lineage7 broad lineages

R: Seurat 5, nothing to install. Python: 3.9 or newer; numpy, pandas, scipy, anndata. MIT licence. Full instructions: github.com/dndn0254/gigasatlas.

Quick start
# R, on a Seurat object (no install)
source("https://raw.githubusercontent.com/dndn0254/gigasatlas/main/R/gigasatlas.R")
seu <- gigasatlas_annotate(seu, model = "hemocyte", group.by = "seurat_clusters")
head(seu[[c("gigas_label", "gigas_prob", "gigas_status")]])
z <- gigasatlas_score_clusters(seu)      # tissue not in the atlas
seu <- gigasatlas_convert_ids(seu)       # only if genes use Roslin v1 IDs

# Python, on AnnData or a 10x folder
pip install git+https://github.com/dndn0254/gigasatlas.git
gigasatlas annotate sample.h5ad --model hemocyte --table names.tsv
gigasatlas enrich my_de_genes.txt
